# Desh Vromon — Week 3–4 Development Sprint 1

## Implemented
- Authentication (signup, login, logout)
- Browser localStorage demo database
- Navigation across all six existing UI screens
- Destination search and favorites
- Trip planner interaction and itinerary generation
- Accommodation selection and booking confirmation
- Provider booking confirmation actions
- Responsive layout

## Run
### VS Code
Install **Live Server**, open this folder, right-click `index.html`, then choose **Open with Live Server**.

### Terminal
```bash
python -m http.server 8000
```

## Important
This is an academic frontend prototype. Passwords in localStorage are not secure and must be replaced by a real backend/database in Week 5–6.
